问题 4：README 需要补充“非目标”

目前 docs 有：

threadctl-rs will not:

- freeze
- kill
- replace scheduler

非常好。

但是 README 首页应该直接出现。

原因：

Android 用户看到：

线程控制器

第一反应：

杀后台？

冻结？

省电魔改？


需要第一屏声明：

例如：

## What threadctl-rs is not

threadctl-rs does not:

- kill apps
- freeze processes
- replace Android LMKD
- replace Linux scheduler

It only applies explicit user-defined thread policies.

这会减少大量误解。

问题 5：DecisionEngine 文档需要增加“禁止行为”

Skip
Degrade

很好。

但建议明确：

DecisionEngine:

允许：

是否执行策略

DecisionEngine cannot:

- select CPUs
- migrate tasks
- kill processes

避免未来贡献者扩大职责。
