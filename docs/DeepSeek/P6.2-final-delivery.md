## 一、DeepSeek V4 Pro 架构基线（前序，本文档的根）

### 分层架构（V4 Pro 定稿，GPT/Claude 审过）

```text
KDL/TOML
  ↓
Config Compiler（profile/group 展开，P6.2/6.3）
  ↓
Rule Compiler → RuleSet（PackageMatcher：exact + wildcard 并存）
  ↓
ThreadMatcher（fnmatch 命中集）
  ↓
Policy Merge Engine（merge.rs：字段级覆盖 + 继承，CSS 模型）
  ↓
DecisionEngine（gate：Allow/Skip/Degrade + reason）
  ↓
Backend Apply（LinuxV1Backend：affinity/cpuset/sched/uclamp）
  ↓
内核（sched_setaffinity / cpuset tasks / sched_setscheduler / sched_setattr）
```

核心原则（历轮审查沉淀）：
1. **匹配与合并解耦**：RuleSet 只产 RuleMatch{index, source}，merge.rs 定策略
2. **group/profile 属编译期**：Config Compiler 展开，RuleSet 不感知高级语义
3. **来源并存不互斥**：exact override wildcard，低优先级填充（CSS 继承）
4. **DecisionEngine = gate 非调度器**：输出 Allow/Skip/Degrade，不返回 Policy，不读 proc
5. **Backend 按能力抽象**：trait 三件套 + LinuxV1Backend，无空 V2 stub
6. **错误可见性**：规则不静默丢弃，配置/内核失败全部告警 + audit
