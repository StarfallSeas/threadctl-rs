## 二、最终实现状态

### detect_clusters v2（M1）

```text
N=1 → Unknown
N=2 → 全大核（ratio < 2.0 且 min_cap > 300）→ Big+Prime；否则 Little+Big
N=3 → Little/Big/Prime（SM8475/SM8550）
N=4 → Little/Mid/Big/Prime（SM8650）
N≥5 → Little/Mid/Big×k/Prime
```

- `classify_clusters()` 纯函数（单测友好）
- `CpuClusterKind::Mid` + `config_name()` 显式名称（防 Debug 依赖）

### DVFS 域探测（M2）

- `detect_dvfs_domains()`：cpufreq policyN，related_cpus 优先 / affected_cpus fallback
- 启动日志：`DVFS domains: [0-2, 3-6, 7]`
- 修复：sysfs 空格分隔兼容（`"0 1 2"`）

### cluster mid + fallback（M3）

- `cluster "mid"` 配置支持（is_valid_name 加 mid）
- BUG-M2：fallback 从静默 `clusters.last()` → 同档近似 + 告警
  （little/mid→big，big/prime→prime，单集群 Unknown 兜底）
- 真机：SM8550 上 `cluster "mid"` → fallback big + warning ✓

### 示例文件（M3，不内置默认规则）

- `examples/threadctl.kdl`：完整示例（mid + 抖音 cpus 直达 + SoC 说明）
- `examples/profiles.kdl`：游戏/聊天/视频/音乐四档模板
- `examples/groups.kdl`：社交/游戏/工具/音乐包组通配模板

## 四、SoC 适配最终结论

| SoC | 布局 | cluster 名 | 验证方式 |
|---|---|---|---|
| SM8475 (8+ Gen1) | 1+3+4 | little/big/prime | 单测 |
| SM8550 (8 Gen2) | 1+4+3 | little/big/prime | 真机 ✅ |
| SM8650 (8 Gen3) | 容量 1+3+2+2 / 电压域 1+2+3+2 | little/**mid**/big/prime | 单测 + 用户确认 |
| SM8750 (8 Elite) | 2+6 全大核 | big/prime（无 little/mid） | 单测 + fallback 语义 |
| SM8850 (8 Elite 2) | 2+6 全大核 | big/prime | 单测 |

**通用性保障**：运行时自动探测（capacity + cpufreq 域），无 SoC 硬编码——
厂商魔改（如小米把 cpu3 划入 big）自动跟随。
