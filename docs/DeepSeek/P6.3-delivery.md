## 一、M1：detect_clusters v2（`fa8a6a5`）

### 变更

`crates/core/src/topology.rs`：
1. **`CpuClusterKind::Mid` 新变体**——中核档（4 组容量 SoC，SM8650 的 A720@3.0GHz）
2. **`classify_clusters()` 纯函数**（pub(crate)）——分组逻辑从 sysfs 读取中提取，单测友好
3. `detect_clusters()` 重构为：读 sysfs → 组装 `(capacity, cpus)` 切片 → 调 `classify_clusters`

### 分组规则

```text
N=1 → Unknown（同构）
N=2 → 全大核判定：容量比 < 2.0 且 最低组 > 300 → Big+Prime（SM8750/SM8850）
      否则 → Little+Big（传统 big.LITTLE）
N=3 → Little/Big/Prime（SM8475/SM8550，不变）
N=4 → Little/Mid/Big/Prime（SM8650）
N≥5 → Little/Mid/Big×k/Prime（第一中间=Mid，其余=Big）
```

**全大核判定**（Claude P6.3-规划-1：AND 逻辑，非 OR）：
- `ALL_BIG_MAX_RATIO = 2.0`（容量比上限）+ `ALL_BIG_MIN_CAPACITY = 300`（最低组下限）
- 双条件同时满足才判全大核——防新一代高效小核（capacity>300 的 A5x 变种）误判
- SM8550 实测：1024/280 ≈ 3.66 > 2.0 → 正常判 Little+Big ✓

## 二、M2：DVFS 域探测（`4750ed8`）

### 变更

`crates/core/src/topology.rs`：
1. **`detect_dvfs_domains()`**——枚举 `/sys/devices/system/cpu/cpufreq/policyN/`，
   `related_cpus` 优先（完整频率域，含离线 CPU），`affected_cpus` fallback
   （Claude P6.3-规划-3）
2. **`CpuTopology.dvfs_domains: Vec<CpuSet>`** 字段 + Default + init_cpu_topo 填充

`crates/daemon/src/main.rs`：
3. 启动日志打印：`DVFS domains: [0-2, 3-6, 7]`

### 发现并修复的 bug

**sysfs 空格分隔**：`related_cpus`/`affected_cpus` 是空格分隔（`"0 1 2"`），
原 `parse_cpu_ranges` 只按逗号 split → 首次探测只得到 `[7]`（单 CPU 无空格才解析成功）。
修复：`parse_cpu_ranges` 兼容 `,` / 空格 / 制表符三种分隔。

### 真机验证（SM8550）

```text
DVFS domains: [0-2, 3-6, 7]
```
与容量分组（Little 0-2 / Big 3-6 / Prime 7）完全一致。

### 新增单测（1）

`parse_sysfs_space_separated`：`"0 1 2"` → `0-2`；混合 `"0 1,4-5"` → `0-1,4-5`。

## 三、M3：cluster mid 配置 + BUG-M2 fallback（`5930bea`）

### 变更

`crates/core/src/topology.rs`：
1. `CpuClusterKind` 加 `PartialEq`（fallback 匹配用）

`crates/core/src/config.rs`：
2. **`is_valid_name` 加 `"mid"`**（Claude LOW-3）
3. **BUG-M2 修复**：cluster fallback 从 `clusters.last()`（最高容量，静默）改为
   **同档近似 + 告警**：
   - little/mid 不可用 → **big**（低性能组，全大核 SoC 正确兜底）
   - big/prime 不可用 → prime
   - 单集群 Unknown → 唯一集群（兜底）
   - fallback 时输出 `warning: ... using big cluster instead`

`examples/`：
4. `threadctl.kdl` 更新：cluster 说明（4 名 + fallback）+ SM8650 mid 示例 + 抖音 cpus 直达示例
5. **`profiles.kdl` 新建**：游戏/聊天/视频/音乐四档手写模板（P6.3 裁决：不内置默认规则）
6. **`groups.kdl` 新建**：社交/游戏/工具/音乐包组通配模板 + exact>wildcard 继承示例

`README.md` / `README.en.md`：
7. cluster 行更新：`little / mid / big / prime` + 同档 fallback 说明
